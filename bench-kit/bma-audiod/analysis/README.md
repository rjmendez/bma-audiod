# analysis/ - multi-beam analysis of the live BMA360 stream

Runs next to the bridge (`../pc`). The bridge fans all 8 beams out (`--all-to wsl:48300`, one BMAA slot per beam, same 48 kHz sample clock); `host.py` aligns them and runs plugins on windows of all 8 beams.

Scope: classification, embeddings, metadata. Nothing is transcribed.
- No audio is written to disk unless `--clip-audio` is on (flag default OFF; the supervisor passes it when `<root>\enable_clip_audio.txt` exists); otherwise audio exists only in 12 s RAM rings.
- A window the tagger scores as speech (p >= 0.30) produces no stored embedding.
- Wildlife clips add visual-only products (spectrogram + signatures, not invertible to speech); audio clips (24 h retention, speech guard, human-voice purge) only with `--clip-audio`.
- `status.json` carries `audio_written` (false unless `--clip-audio` is on and an audio clip was written in this run).
- `status.json` `pool_workers`: worker threads, one per heavy plugin, minimum 3.
- `summarize.py` counts audio-like files under the output dir outside `clips/` (must be 0) and reports `clips/` separately.

## Wildlife clips (`clips.py`, spec `../contracts/specs/clips.md`)
- Audio OFF by default. Without `--clip-audio` the capture is visual-only: spectrogram PNG, signature JSON, index record for a wildlife sound whose BirdNET event confidence is strictly above `--clip-min-conf` (default 0.85, accepted 0.05 to 1).
- Visual-only rules (`clip_render.py`, `clip_features.py`, spec "Visual-only"): everything below 3.5 kHz removed before anything is computed; PNG = 96 log rows from 3.5 kHz up, 50 ms per column (non-overlapping), 8-bit magnitude only; level envelope 20 values/s; dominant-frequency track 10 values/s.
- `--clip-audio` (supervisor passes it only when `<root>\enable_clip_audio.txt` exists; never the installer or container): short lossless FLAC held 24 h (`--audio-retention-h`). Confirmed human voices are purged from stored clips each sweep (`meta.clips_purged_human`).
- Wildlife = taxa group bird / insect / amphibian / mammal / other-bio. `taxa.json` must be deployed next to `host.py` (without it every group is null and nothing is stored). Domestic/farmyard animals, pet parrots, mechanical and human classes excluded by `clip_exclude.json`.
- Privacy guard, fail closed: nothing stored unless the tagger timeline covers clip start - 5 s to end + 5 s with no speech (`speech_p` < 0.10), no human-sound tagger label (laughter, cough, scream ...) and no `Human*` BirdNET label; tagger off or a hole = nothing stored.
- Layout `<--out>/clips/YYYYMMDD/<id>.flac|.png|.json` + `index.jsonl`;
  - PNG/JSON/index stay 14 days (`--sidecar-retention-days`). Bounds: 6 clips per species per UTC hour (highest confidence kept), 512 MB audio cap, 256 MB sidecar cap, bounded writer queue; counters in `status.json` `meta` and `clips`.
- Flags: `--no clips`, `--clips-dir`, `--clip-min-conf`, `--clip-cap-per-species-hour`,
  `--audio-retention-h`, `--sidecar-retention-days`, `--clip-max-s`, `--clip-pre-s`, `--clip-post-s`, `--clip-audio-cap-mb`,
  `--clip-sidecar-cap-mb`, `--clip-sweep-s`, `--clip-guard-s`, `--clip-speech-p`, `--clip-hold-s`,
  `--clip-min-beams` (default 2: distinct beams that reported the species within the event; 1 = rule off), `--clip-skip-out-of-region`, `--clip-exclude`.
- Tests: `python test_clips.py`; mutations: `python mutation_clips.py`.

Plugin details:
- `coherence`: gated/dead windows (beam muted > 40 dB) excluded and counted; noise floor = 10th percentile of the last 900 used-window levels; an interval open at shutdown is written with `partial: true`.
- `coherence_report.py <out>/coherence.jsonl` prints the verdict per band (spec beam-coherence "Verdict rules").
- `perch`: never records speech-flagged windows or human-voice labels; embeddings only with `--perch-embeddings`.
- `bursts`: speech-flagged windows excluded (records held back 15 s).
- `bursts_report.py <out>/bursts.jsonl [--ambient history/ambient_temp.jsonl]` prints the hourly table; `--replay-dsp dsp.jsonl --from .. --to ..` replays recorded `transient` records; `bench_plugins.py` times it.
- `indices`: speech-flagged windows excluded and counted (needs `tags`, or `--indices-without-speech-gate`).
- `indices_report.py <out>/indices.jsonl` prints a daily table and each index's correlation with the chorus band.
- `compare_maad.py` (PYTHONPATH = scratch overlay with scikit-maad) cross-checks formulas.
- `mixscore`: switch on with `host.py --mixscore [--mixscore-every N]` (N default 4) or, under `run_analyzer.sh`, `mixscore.json` (`{}` or `{"every": N}`) next to it; delete the file to switch off.
- `mixscore` cost: 52 ms CPU per second of audio at N=1 (158 ms per 3 s window, `bench_plugins.py`; spec `contracts/specs/mixscore.md`), 750 MB memory; reported in `status.json` `plugins.mixscore`. Report: `python -I mixscore_report.py <analysis dir>`.

All plugins write metadata only. PANNs was trained at 32 kHz: its input is the 48 kHz beam downsampled 2:3 (never upsampled); everything else is 48 kHz native.

- `python summarize.py [<dir>] [minutes]` prints a digest.

Models install under `$BMA_MODEL_DIR` (default `<data-dir>/models`; `install_models.sh`, overlay in `<model-dir>/overlay`). Plugins that fail to start are reported in `status.json` and skipped.

Tests: `python test_analysis.py` (audioeval venv; synthetic native-48 kHz signals); `python -I test_indices.py [--skip-e2e]` (maad cross-check needs scikit-maad on PYTHONPATH);
- `python -I test_coherence.py` (also with a Python that has `jsonschema`);
- `python bench_plugins.py` prints dsp, spatial, coherence, indices cost. All analysis suites sequentially, exit 1 on any failure: `python -I run_tests.py` (audioeval venv; `run_tests.py test_beam_agreement` for one).

Notes:
- WSL caps UDP receive buffers at 208 KB; the supervisor raises `rmem_max` as root.
- `transformers` returns ModelOutput objects from `get_*_features` and wants `audio=` not `audios=`.
- The CLAP weights are `pytorch_model.bin`, not safetensors.

## Adding a plugin (the plugin manifest)

All analysis plugins are registered in ONE file, `plugins.manifest.json` (design: `docs/design/w3-plugin-manifest.md`). `manifest.py` reads it and
derives what used to be edited by hand in a dozen shared files: the `--no` help text, the Outputs list of the host docstring, the plugin flags, the
module imports, the factories, the `status.json` `meta` counters, the list of files `pc/install_task.ps1` installs, the
contract tables of `contracts/check_contracts.py`, and the plugin table below. A new plugin is new files plus one manifest entry:

1. **The plugin module** `analysis/<name>.py`: a class with `name`, `win_s`, `hop_s`, `heavy`, `process(x, t_wall) -> (records, embedding_or_None)`, `stats()` (a dict
   with an `errors` count), and a top-level `make(ctx)` that returns the instance (`ctx.args` is the parsed command line, `ctx.started` the names of the plugins that
   started before it, `ctx.taxa`, `ctx.classify_dir`, `ctx.out_dir`, `ctx.shared`). Raise from `make` to say why it cannot start; the host reports it in `status.json` and runs on.
2. **The contract** (new interface): `contracts/schemas/<x>.schema.json` (with `x-contract-version`, `x-discriminator`, `x-files`), `contracts/specs/<x>.md` (header
   `contract_version:`), `contracts/fixtures/<x>.jsonl` (every record kind), and a changelog entry as a fragment `contracts/changelog.d/<interface>.md`
   (a line `<interface> <version> ...`; fragments never conflict, `CHANGELOG.md` is for history).
3. **The manifest entry**: append to `plugins` in `plugins.manifest.json`, in registration order (that is the `status.json` order and the process order). Keys:
   `name`, `module`, `files` (analysis files deployed for it), `import` (`required` = a failure stops the host, `optional` = reported and the plugin is off, `lazy` =
   imported inside `make`), `make` (`module:function`), `heavy` (must equal the class attribute: checked), `deploy` (`pc`, `image`), `outputs`, `flags` (argparse flags: types
   `int`, `float`, `str`, `flag`; `cli_slot` `tail` puts them after the core flags), `hooks`, `meta_counters` (`meta.<name>` = sum of `stats()` keys), `contract`
   (name, version, schema, spec, fixtures, live files, optional `tests`) and `readme` (the table row).
4. **Hooks** are declared, never discovered: `consumes_speech` (method `note_speech(t_start, t_end, speech_active)`), `consumes_tag` (`note_tag(t_end, speech_active, win_s)`),
   `observes` (`observe(plugin, records, t_wall)`, in-process records of the others), `cost` (`cost()` merged into the status entry), `flush` (`flush()` at shutdown). A method
   that exists but is not declared, or a declaration without the method, is an error (`manifest.py check`, `test_manifest.py`). Plugin-specific hand-offs are the named
   `feeds` of `wiring.py`; they are not generalised.
5. **The image**: add the plugin's files to the literal `COPY analysis/...` line of `docker/analyzer.Dockerfile` (only when `deploy` has `image`); `docker/test_install_lists.py` names the file if it is forgotten.
6. **Regenerate the README table**: `python manifest.py readme --write` (a conflict in that block is resolved by regenerating, never by hand).
7. **Tests**: `python manifest.py check` (the manifest against the files), `python test_manifest.py`, `python ../contracts/test_contracts.py` (the table-driven checks run for
   your contract with no edit), and `python ../docker/test_install_lists.py`. (The one-time golden proof that the manifest refactor changed no output of the host, the installers or the contract tables is retired: docs/design/w3-plugin-manifest.md, 12.7.) Bespoke contract tests go in
   a file such as `contracts/tests/<name>_contract.py` listed in your entry's `contract.tests` as `tests/<name>_contract.py` (explicit, no glob; it runs inside test_contracts.py's namespace: check, drifts, mod, SCH, ...).

Not manifest-driven on purpose: `bench_plugins.py` (bespoke timing) and the opt-in file switches of `run_analyzer.sh`. `test_manifest.py` proves the steps above with a throwaway
demo plugin: it touches exactly the new files, the manifest, the generated README block and the Dockerfile COPY line, and nothing else.

## Offline tool `beam_response_map.py` (stdlib only, run by hand, not a plugin)
`python -I beam_response_map.py --analysis-dir <data-dir>/analysis [--bands-log <data-dir>/reports/beam_bands.jsonl] [--taxa FILE] [--source NAME ...] [--epoch ISO=LABEL ...] [--out FILE] [--json]`
- Joins bird events to the 8-beam level vectors of `spatial.jsonl` (rows t-2..t of each 3 s event), subtracts each beam's +-900 s median, reports A1 (first-harmonic amplitude over the ring), R,
  Rayleigh/permutation/bootstrap statistics against event-free controls of the same UTC hours, per source, band and segment;
  - verdict `go`/`weak`/`no_go`/`insufficient`/`inconsistent`.
- Recording clusters separated by gaps analysed separately; `.1` rotated files read by default. Human voice never a source;
  - events or controls within 5 s of a human-voice record or `tags.jsonl` `speech_active` row never used (no human-voice count reported; taxa table required, exit 2 without it). Detections < 60 s apart form one bout;
  - tests run on per-bout means; a source needs >= 10 bouts.
- `--bands-max-rows` (default 60000, last rows) and `--bands-since ISO` bound the beam_bands read; rows sorted by time on load. Contract `beam-response-map`. Read-only; `--out` refused inside the analysis directory.
- Tests: `python -I test_beam_response_map.py [--mutations]`.

## Reliability report

`python -I reliability_report.py --data-dir DIR [--since ISO] [--json] [--write-confusions PATH] [--taxa FILE] [--top N]`: read-only, label-free report on `DIR/analysis/birds.jsonl` (rows `bird` / `bird_filtered`),
- `DIR/history/ambient_temp.jsonl` (reader rule of specs/ambient-temp.md: nearest past hour, at most 3 h old, else unknown),
- taxonomy table: `analysis/taxa.json`, else `../ui/taxa.json`.
- Writes only the file named by `--write-confusions` (refused, exit 2, when it names an input file, a directory, or a path in a missing directory).
- Missing/unreadable taxonomy table: exit 1, nothing printed or written; an existing `confusions.json` is never overwritten with `{}`.
- Advice only. Evidence: multi-beam agreement, temperature plausibility of insect and frog detections, out-of-region reports next to an in-region species.
- Event = rows of one species with consecutive timestamps <= 3 s apart (confidence = max, beams = distinct beams). Non-species labels (taxonomy `non_species`, e.g. engine) and any `human` label are not reported.

### Constants and decision rules

| constant | value | meaning |
|---|---|---|
| `EVENT_GAP_S` | 3 | birds windows are 3 s |
| `HIGH_CONF` | 0.85 | existing pipeline gate |
| `MIN_EVENTS` | 10 | minimum events for a verdict |
| `MIN_HIGH_EVENTS` | 5 | events at >= 0.85 needed before 'trustworthy' |
| `TRUSTED_MULTIBEAM_SHARE` | 0.8 | share of those events on >= 2 beams (point estimate) |
| `TRUSTED_MULTIBEAM_LOWER` | 0.6 | Wilson lower bound of that share |
| `WILSON_Z` | 1.645 | z of the Wilson interval (one-sided 95 %) |
| `MIN_SPECIES_MULTIBEAM_SHARE` | 0.5 | share of ALL the species' events on >= 2 beams |
| `TEMP_MIN_KNOWN` | 10 | events with known temperature needed for a temperature verdict |
| `INSECT_COLD_C` | 10 | insects silent below this |
| `INSECT_SUSPECT_SHARE` | 0.5 | insect species with this share of events below `INSECT_COLD_C` is suspect |
| `AMPHIBIAN_COLD_C` | 5 | amphibian cold cutoff |
| `AMPHIBIAN_SUSPECT_SHARE` | 0.8 | share below `AMPHIBIAN_COLD_C` (10 C share still printed) |
| `CONFUSION_MIN_CONF` | 0.7 | filtered reports at >= this count as high confidence |
| `CONFUSION_WINDOW_S` | 5 | partner = in-region row of same group and genus (first word of scientific name) within +-5 s |
| `CONFUSION_MIN_REPORTS` | 10 | reports needed for a confusion |
| `CONFUSION_MIN_SHARE` | 0.6 | share of reports with the same partner species |
| `CONFUSION_NULL_SHIFT_S` | 600 | base-rate control: partner looked for around each report time shifted by +-600 s |
| `CONFUSION_MAX_NULL_RATIO` | 0.5 | shifted share at most this fraction of the real share |
| `MIN_CONF_FLOOR` | 0.5 | suggested minimum confidence never lower |

Verdict, first match wins:

| # | verdict | rule |
|---|---|---|
| 1 | `confusable with X` | confusion evidence qualifies (reports >= 10 and >= 60 % with the same partner X, and the partner's share around the report times shifted by +-600 s is at most 50 % of the real share) |
| 2 | `too few events` | events < 10 |
| 3 | `out of region` | every report of the species was rejected by the geofilter (`bird_filtered` or `in_region` false); never `trustworthy` |
| 4 | `suspect: temperature implausible` | insect: >= 50 % of events below 10 C; amphibian: >= 80 % below 5 C; with >= 10 known temperatures |
| 5 | `no high-confidence events` | no event at >= 0.85 |
| 6 | `needs second beam` | fewer than 5 events at >= 0.85, or fewer than 80 % of them on >= 2 beams, or the lower bound below 60 % (Wilson), or fewer than 50 % of all the species' events on >= 2 beams |
| 7 | `trustworthy at 0.85` | otherwise |

### Suggested rules (`--json`)
Top level `version` (1), `advice_only` (always true), `species` (keyed by scientific name);
- Keys sorted, LF.
- Per species: `common`, `group`, `verdict`, `detail`, `min_confidence` (>= 0.5), `min_beams`, `stats` (`events`, `events_high`, `share_high`, `median_conf`, `max_conf`, `mean_beams`, `share_multibeam`,
  `share_multibeam_high`, `share_multibeam_high_lower` (Wilson lower bound used by rule 6; null without events at >= 0.85),
  `hours_active` = distinct UTC clock hours, `temp_known`, `share_below_5c`, `share_below_10c`; last three null outside insect / amphibian groups).
- `out_of_region` true when some rows were rejected by the geofilter, `all_out_of_region` when every row was.
- Advice: trustworthy -> 0.85 and 1 beam; needs second beam / too few events / no high-confidence events -> 0.85 and 2 beams; temperature implausible / confusable / out of region -> 0.95 and 2 beams.

### `confusions.json`
Written deterministically by `--write-confusions PATH` (sorted keys, 2-space indent, LF, no timestamps); only qualifying entries. Keyed by out-of-region common name:
`{"<label>": {"likely_as": "<in-region common name>", "scientific": ..., "likely_as_scientific": ..., "evidence": {"reports", "co_occurring", "share", "min_confidence", "window_s"}, "source": "co-occurrence within 5 s"}}`
Keys: `likely_as`, `scientific`, `likely_as_scientific`, `evidence`, `source`. `reports` = out-of-region reports at >= `min_confidence`; `co_occurring` = those with a `likely_as` row within `window_s` seconds; `share` = ratio (4 decimals).

## pcen.py (library, not yet imported by the analyzer)
Per-channel energy normalisation (Wang et al., ICASSP 2017), numpy only, time on axis 0: `pcen(E, s=0.025, alpha=0.98, delta=2, r=0.5, eps=1e-6, init="librosa", scale=1)`, `PCENStream` (explicit state `M`, `feed`/`feed_one`, bit-identical to batch for any chunk split),
- `smoothing_from_time_constant(tc_s, frame_rate_hz)`, `fixed_point(e)`, `render_u8(power_rows, frame_s)` (8-bit image, <= 96 rows, columns >= 50 ms, row 0 = highest frequency).
- E is linear power, eps absolute: `scale=INT16_POWER` for full-scale-1.0 floats. `init="librosa"` (M(-1)=1) matches librosa to 5e-15; `init="first"` starts from the first frame.
- Tests: `python -I test_pcen.py` (exit 77 = librosa agreement skipped, not a pass; also in the audioeval venv), `python -I mutation_pcen.py`.

## beam_agreement.py (offline, read only)
`python -I beam_agreement.py --birds <birds.jsonl> [--ambient <ambient_temp.jsonl>] [--labels <labels.jsonl>] [--gap-s 5] [--null-trials 200] [--null-seed <int>] [--out <file>]`: does the same species on two beams in the same 3 s window tell more than BirdNET's confidence? Writes a `beam_agreement_report` (contracts/specs/beam-agreement.md) with a pre-registered `decision`.
- Works on a copy of the data; refuses `--out` inside any input directory; no audio.
- `shuffle_null` (1.1.0): per-beam report times shuffled within species/hour; real vs shuffled pass rate and excess per bin and per measured quantile band; report-only.

- Tests: `python -I test_beam_agreement.py` (stdlib only). All analysis suites, sequentially, exit 1 on any failure: `python -I run_tests.py` (audioeval venv; `run_tests.py test_beam_agreement` for the stdlib one).

## events.py (library, pure stdlib)
`build(rows, gap_s, kinds, drop_human, dedup)` -> clusters + `Result.check()` (input = reports in events + named rejections; raises `ConservationError`); `Cluster.id` = `ev1-<24 hex>` content hash; `diff(prev, clusters)` -> kept / superseded / orphaned; `merge_aliases`, `resolve`.

## Supervisor opt-ins
Read at every analyzer start:
- `<root>\enable_clip_audio.txt` (empty file) = `--clip-audio`.
- `<root>\analyzer_args.txt` = extra host.py arguments, one token per line; blank and `#` lines ignored; Windows absolute paths become WSL paths; lines with a double quote or trailing backslash skipped.
- `run_analyzer.sh` takes them as 4th positional (`1` = `--clip-audio`) and the arguments after it.
