## Contract rules

- `novelty.score` may equal 3.0 with `novel: true`; schema allows `score >= 3.0` for novel records.
- Health temperatures may be empty strings with null `temp_*_c`.
- Daemon status may be `{"state":"starting"}`; only `state` is required.
- `health_unparsed`: a line of NUL bytes followed by an intact JSON object is stored whole.
- Discriminators: analysis records `k`, board_debug records `type`, `health` records both. New JSONL interfaces MUST use `type`.
- `bridge_status.targets` lists `--to` targets only. `pps`, `loss_pct`, `blocks_all_zero_frac` are per interval; `gaps`, `backwards`, `bad`, `blocks`, `pkts` cumulative.
- Monitor map: 42 lines per sweep (DSPs 4-9 x slots 0-6); slot 4 is not an audio channel; `rms_dbfs` null.
- Beam numbering: analysis "beam 1" = slot 0 = Dante Tx 1 = vendor "Beam 2"; vendor Beam 1 is not routed.
- `beam_bands.t_us` is record production time; use `idx` and cable anchors for the audio axis.
- `sink_status.json` and `beam_bands.jsonl` are optional live files.
