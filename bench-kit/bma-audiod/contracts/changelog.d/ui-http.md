## ui-http 1.11.0 - 2026-10-27 (minor, additive: the advisory artifact flags on the dashboard; artifact-gate phase 2)

- ui-http 1.11.0 - additive: insect and mechanical events carry an optional `artifact_flags` (the `artifact-gate` 1.0.0 object, `$defs/artifact_flags`, also `artifact_reason` / `artifact_level`), computed at read time by `ui/bma_ui.py` from `history/ambient_temp.jsonl` (the ambient-temp reader rule) and the dsp `transient` records (burst evidence only when the +-30 s window is covered; else null); new query parameter `artifact` = `any` (default, identical to 1.7.0) | `none` | `only` on events, density and species, echoed as `artifact`; species rows gain `artifact_events`, the response `artifact_events_total` and `artifact_unscored_events` (rollup-sourced events are never scored); `GET /api/status` gains `artifact_gate` (enabled, parameters, ambient and transient feed state, events scored and flagged in 24 h); server flag `--no-artifact-gate`. Nothing is ever deleted or hidden by default, no existing field changes, groups outside insect and mechanical carry no key, human-voice labels stay hidden everywhere. The dashboard reads `artifact_gate.py` from its own directory (the installers copy it there) or `../analysis`; absent = no flags and `status.artifact_gate.available` false. The analyzer is unchanged (no CPU cost, no restart). artifact-gate stays 1.0.0 (its schema did not change; the ui-http copy of the object is asserted equal). Fixtures regenerated by `contracts/tools/make_ui_fixtures.py` (a cold hour and 25 diffuse transients are now part of the synthetic tree, the events example is the insect view).
